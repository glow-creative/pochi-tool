# ポチツール

クリックした場所と同じ色の範囲を、透過したり塗りつぶしたりできるイラスト編集ツールです。

**https://glow-creative.github.io/pochi-tool/**

- PC と iPad のブラウザで使えます。
- 画像はブラウザの中だけで処理します。外部へは送信しません。

## はじめかた

上の URL を開くだけで使えます。インストールは要りません。ファイル一式を保存して、`index.html` を直接開いても同じように動きます。

| 項目 | 内容 |
|---|---|
| 開ける画像 | PNG・JPG・WebP |
| 大きさの上限 | 1,200万画素、長辺 16,384px |
| 開きかた | 「画像を選ぶ」ボタン、ドラッグ＆ドロップ、`⌘/Ctrl + O` |

## 基本の使い方

1. 画像を開きます。
2. 「消しゴム」か「バケツ」を選びます。
3. 消したい場所、塗りたい場所をクリックします。
4. 範囲が合わないときは、「色の許容範囲」を動かします。同じ場所でやり直せます。
5. 「PNGで保存」で書き出します。

塗りが漏れるときは、先に「区切り線」で止めたい場所に線を引きます。

## ツール

| ツール | キー | すること |
|---|---|---|
| 消しゴム | `E` | 範囲を透過する |
| バケツ | `B` | 範囲を塗り色で塗る |
| 区切り線 | `G` | 範囲の広がりを止める線を引く |

### 消しゴム・バケツ

- 範囲の広さは、「色の許容範囲」で決まります。
- 塗り色を選ぶと、バケツに切り替わります。
- バケツは線画を塗りません。線を塗りたいときは、線をクリックします。

### 区切り線

点を置くと、点どうしが直線でつながります。この線が、範囲の広がりを止めます。線は、保存した PNG には入りません。

| したいこと | 操作 |
|---|---|
| 点を置く | 何もない場所をクリック。点操作中は新しい線を始める |
| 点を動かす | 点をドラッグ |
| 角の形を変える（角・滑らか） | タブレットでは「角の形を変える」を押す。マウスでは点をダブルクリック |
| 輪にする | 最初の点をクリック（点が3つ以上のとき） |
| ほかの点につなぐ | 線を引いている途中で、ほかの点をクリック |
| 線の続きを描く | 線を引いていないときに、点をクリック |
| 線を引き終える | 「＋ 新しい線」を押す |
| 点を消す | 「1点消す」を押す |
| すべて消す | 「すべて消す」を押す |

「＋ 新しい線」などのボタンは、サイドバーの吹き出しにあります。

**点と線について**

- 点を置くとき、押したままドラッグすると位置を調整できます。
- 「角の形を変える」と「1点消す」は、選んでいる点にすぐ働き、そのまま続けて点を操作できます。
- 点操作中に点をクリックすると、角の形の変更または削除を続けます。点をドラッグしたときは、形を変えたり消したりせずに移動します。
- 点操作中に点のない場所をクリックすると、そこから新しい線を始め、点操作を終えます。
- 同じ点操作ボタンをもう一度押すと取りやめます。もう一方を押すと、その操作へ切り替わります。
- 点の上にカーソルを置くと、点が塗りつぶしで表示されます。
- 点は角で始まります。角の点は四角、滑らかな点は丸で表示されます。
- 角の点の前後は、直線でつながります。
- 輪の内側を塗ると、外へは漏れません。
- 輪にしたときと、ほかの点につないだときは、そこで線が引き終わりになります。
- 端どうしをつないだときは、2本が1本の線になります。
- 線の途中につないだときは、2本のままです。
- つないだ点を動かすと、両方の線が一緒に動きます。
- つないだ点を滑らかにすると、線はそこで曲がります。
- 線の端の点をクリックすると、その線の続きを描けます。
- 線の途中の点をクリックすると、そこから新しい線が分かれます。
- 画像の外の余白にも、点を置けます。

**消すとき・戻すとき**

- 選んでいる点は、`Delete` キーでも消せます。置いたばかりの点も、選ばれた状態です。
- 区切り線の操作は、「戻る」で戻せます。
- 区切り線を変えても、「編集中」の表示にはなりません。
- 「画像全体」を選んでいるときは、区切り線は効きません。

## 選ぶ範囲の設定

### 色の許容範囲

クリックした色に、どれくらい近い色まで選ぶかを決めます。0〜100 で、はじめは 50 です。

- 編集の直後に動かすと、同じ場所をやり直します。
- やり直しは、履歴に1回分だけ残ります。
- 動かしている間は、やり直す場所に印が出ます。
- やり直しが終わるまで、数値の左で小さな円が回ります。
- 数値欄に直接入力できます。`↑` `↓` で1ずつ変わります。
- キーボードの `1` で下げ、`2` で上げます。

次の操作をすると、やり直しが確定します。

- ツールや色を変える
- 設定の欄（許容範囲から「画像全体」まで）以外のサイドバーに触れる
- 保存する
- 別の場所をクリックする
- `Esc` を押す

拡大・縮小やスクロールでは、確定しません。

### 白と黒も含める

ふだんは、次の2つを守っています。

- バケツは、線画を塗らない
- 色のある場所をクリックしたとき、白い紙を選ばない

このチェックを入れると、2つの保護を外します。たとえば、絵のまわりの白いふちまで消したいときに使います。

### つながった所・画像全体

| 設定 | 選ぶ範囲 |
|---|---|
| つながった所（はじめ） | クリックした場所とつながった範囲 |
| 画像全体 | 画像の中の、同じ色すべて |

- 散らばった同じ色をまとめて消すときは、「画像全体」を使います。
- 直前の編集があれば、切り替えたときにやり直します。
- 「画像全体」では、区切り線は効きません。

## 塗り色

| 選びかた | 内容 |
|---|---|
| プリセット | DADS 143色、USWDS 423色。タブで切り替えます |
| 最近使った色 | 13色まで並びます |
| カラーコード | `#RRGGBB` を入力します。`#` は省略できます |
| 自由な色 | カラーコード欄の左の四角から選びます |

- 色を選ぶと、バケツに切り替わります。
- 色見本にカーソルを1秒置くと、色の名前とコードが出ます。
- バケツを選んでいるときは、キーボードでも色を選べます（[ショートカット](#キーボードショートカット)）。

## 表示の拡大・縮小

| したいこと | 操作 |
|---|---|
| 拡大・縮小 | 「＋」「−」ボタン、`+` `-` キー、`⌘/Ctrl + ホイール` |
| 画面に合わせる | 倍率の数字を押す、`0` キー |

- 倍率は 2%〜800% です。
- 画面より小さい画像は、元の大きさのまま表示します。
- 100% 以上では、画素をそのまま表示します。縁の確認に便利です。

## 戻る・やり直す

| したいこと | 操作 |
|---|---|
| 元に戻す | 左向きの矢印ボタン、`⌘/Ctrl + Z` |
| やり直す | 右向きの矢印ボタン、`Shift + ⌘/Ctrl + Z` |
| 最初に戻す | 丸い矢印のボタン（やり直すの右） |

- 画像の編集と区切り線の操作は、同じ履歴に並びます。
- 画像の編集は、最大20回まで戻せます。画像が大きいと、回数は減ります。
- 履歴に残せる画像は、合計 128MB までです。
- 履歴全体は、200件までです。

### 最初に戻す

開いたときの画像に戻します。「元に戻す」との違いは次のとおりです。

| | 元に戻す | 最初に戻す |
|---|---|---|
| 戻る量 | 1回分ずつ | 開いたときまで一度に |
| 押したあと | 「やり直す」で戻せます | **取り消せません** |
| 履歴 | 1つ進む・戻る | すべて消えます |
| 区切り線 | 履歴に並びます | **そのまま残ります** |

- 押すと確認を求められます。
- 編集が1つも無いときは押せません。
- 区切り線を消したいときは、区切り線ツールで消します。

## 保存

- 「PNGで保存」か `⌘/Ctrl + S` で保存します。
- 透過は、そのまま保たれます。
- ファイル名は「元の名前-edited.png」です。
- 保存していない編集があると、ヘッダーに「編集中」と出ます。
- その状態でページを閉じると、確認が出ます。
- iPad の Safari では、「ファイル」アプリの「ダウンロード」に入ります（標準の設定のとき）。

## iPad での操作

Apple Pencil でも指でも使えます。

| PC | iPad |
|---|---|
| クリック | タップ |
| ダブルクリック | ダブルタップ |
| `⌘/Ctrl + ホイール` | 2本指でつまむ |
| スクロール | 2本指でずらす |

- 画面の説明も、「タップ」の表記になります。
- 指1本の操作は、指を離したとき、または少し動かしたときに始まります。2本指の操作と区別するためです。
- Apple Pencil とマウスの操作は、押した時点で始まります。
- 指で区切り線の点を触るときは、少し離れていても掴めます。

## キーボードショートカット

| キー | 動作 |
|---|---|
| `E` `B` `G` | 消しゴム・バケツ・区切り線 |
| `←` `→` `↑` `↓` | 隣のツールに移る（ツールのボタンにいるとき） |
| `1` `2` | 許容範囲を下げる・上げる |
| `←` `→` | プリセットの明るさを変える（バケツ） |
| `↑` `↓` | プリセットの色相を変える（バケツ） |
| `P` | DADS と USWDS を切り替える（バケツ） |
| `⌘/Ctrl + Z` | 元に戻す |
| `Shift + ⌘/Ctrl + Z` | やり直す |
| `⌘/Ctrl + O` | 画像を開く |
| `⌘/Ctrl + S` | PNGで保存 |
| `+` `-` | 拡大・縮小 |
| `0` | 画面に合わせる |
| `Delete` | 選んでいる点を消す（区切り線） |
| `Esc` | 角変更・点削除をやめる、線を引き終える、編集を確定する |

- 入力欄に入力している間は、1文字のキーは効きません。
- 入力欄の中では、`⌘/Ctrl + Z` は入力の取り消しになります。
- `Tab` で、ボタンや入力欄を順に移動できます。

## アクセシビリティ上の既知の制約

次の2つは、ほかを優先して受け入れている制約です。WCAG 2.2 AA への適合を表明するときは、見直します。公共調達の対象にするときも同じです。

### DADS の色見本

- 色見本だけでは、WCAG 2.2 のターゲットサイズ（2.5.8）を満たしません。24px より小さく、間隔も狭いためです。
- 13段階を1行で見渡せることと、キャンバスの広さを優先しています。
- カラーコード、自由な色、USWDS の色見本で、影響を軽減しています。
- Apple Pencil の精度は、使い勝手を補うものです。WCAG の例外としては扱いません。

### キャンバス

- キーボードでは、場所を選んで編集できません。
- マウス、Apple Pencil、指での操作を中心にしているためです。
- WCAG 2.1.1（Level A）には適合しません。

## 仕上がりのしくみ

結果が思いどおりにならないときの参考にしてください。

### 縁

- 縁を滑らかにする処理は、バケツでも消しゴムでも常に働きます。切り替える設定はありません。
- 塗り替えても、縁はギザギザになりません。元の絵のアンチエイリアスを読み取って、新しい色で描き直すためです。
- 前の色のふちも残りません。
- 縁がぼやけた絵は、線画くらいのくっきりした縁に整えます。
- 消しゴムでは、縁の色の濃さを、透明度に置きかえます。
- 斜めの線や曲線では、範囲の内側だけを滑らかにします。
- 許容範囲を広げても、色ムラでガタつかないように処理します。

### 届く範囲

- どこまで届くかは、「色の許容範囲」だけで決まります。
- 値を上げると隣の面まで届き、下げると止まります。
- 届いた面は、塗り色そのものになります。
- 届かなかった面との境目も、ギザギザになりません。
- 範囲は、クリックした場所とつながった部分だけです（「画像全体」を除く）。
- 離れた場所に、点が散ることはありません。

### 線画（バケツ）

- 線画は、許容範囲を上げても塗りません。
- 線の向こう側へも、回り込みません。
- 線を塗りたいときは、線をクリックします。
- 白い紙の線画では、線のアンチエイリアスを保ったまま、背景だけを塗ります。
- 塗りは、輪郭線のいちばん濃いところまで届いて止まります。
- 面の中に残った紙のムラも、一緒に塗ります。
- 線のすぐそばのムラも、線の縁として塗ります。ただし、その先に紙が続くときは、別の面として止まります。
- 「白と黒も含める」を入れると、この保護は外れます。

### 白い紙

- 色のある場所をクリックしたときは、白い紙を選びません。
- そのため、許容範囲を広げても、背景より先に隣の色へ届きます。
- 白い紙を塗る・消すときは、白い場所をクリックします。
- 区切り線を置いたときは、この保護より区切り線を優先します。
- 白い場所をクリックしたときは、線で囲まれていない色も一緒に選ばれることがあります。
- その色を残したいときは、許容範囲を下げるか、区切り線で囲みます。
- 許容範囲のはじめの値 50 は、濃いめの飾りの色が残るように決めています。

**例外：バケツで「画像全体」と許容範囲 100 にしたとき**

- 白い紙も含めて、線画以外の色をすべて塗ります。
- 線画は、このときも塗りません。
- 消しゴムでは、このときも白い紙を選びません。

### 区切り線の境目

- 線の位置は、点を動かして直せます。止める位置も一緒に動きます。
- 線の上の画素は、両側の色で分け合います。そのため、境目は線に沿って滑らかになります。
- 消しゴムで両側を消すと、線の上の画素も残りません。
- 線が交わる所にも、白い点や濃い点は残りません。
- 開きが約5°以上なら、細く尖った区画も先まで塗られます。
- 何度塗り替えても、線の上に前の色は残りません。
- 線が輪郭線と重なる所は、元の絵のまま残します。

## クレジット

塗り色のプリセットは、次の資料を加工して作っています。アプリのパレットの下にも、出典を表示しています。

| パレット | 出典 | 使っている色 | 表示していない色 |
|---|---|---|---|
| DADS | [デジタル庁デザインシステム カラーパレット](https://design.digital.go.jp/dads/foundations/color/color-palette/) | プリミティブカラー、白、Solid Gray | Opacity Gray、Black |
| USWDS | [U.S. Web Design System カラートークン](https://designsystem.digital.gov/design-tokens/color/system-tokens/) | Standard、Vivid | grade 90 |
